## Critical Anti-Patterns (do NOT repeat)

- `edit` with multi-line oldString can delete instead of insert — always re-read the edited region after every edit.
- PowerShell: no `&&` (use `;`), use `npm.cmd` (npm.ps1 blocked), `ls` single path only.
- unittest piped output exits 1 spuriously — trust `OK`/`FAILED` text, not exit code.
- Postgres `CREATE INDEX IF NOT EXISTS` requires an index name; seed inserts need `WHERE NOT EXISTS` (no unique constraint to conflict on).
- R:R float comparison needs 1e-9 tolerance (2.0 computes as 1.9999999999999996).
- Simulator data is pattern/zone-free by construction — WAIT on simulator is correct, not a bug; prove ENTER with synthetic candles.
